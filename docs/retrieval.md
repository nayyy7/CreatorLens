# CreatorLens 轻量检索

> Phase 5 · 可解释的标签匹配 + 关键词评分检索

## 概述

首版检索采用纯规则评分算法，不做向量嵌入或语义搜索。每次检索返回 Top 3 策略卡片，附带匹配字段、相关性分数和匹配原因说明。

## 检索输入

```typescript
interface RetrievalInput {
  category?: string;        // 商品品类
  price_band?: string;      // 价格带
  target_audience?: string; // 目标人群
  content_format?: string;  // 内容形式
  duration_band?: string;   // 时长区间
  weaknesses?: string[];    // Phase 4 发现的弱项
}
```

## 评分算法

### 五维标签匹配评分

| 维度 | 权重 | 匹配规则 |
|------|------|----------|
| 品类 | 0.30 | 精确匹配 +0.30；大类匹配 +0.15；不限品类 +0.05 |
| 价格带 | 0.20 | 精确匹配 +0.20；不限 +0.05 |
| 目标人群 | 0.20 | 精确匹配 +0.20；不限 +0.05 |
| 内容形式/时长 | 0.15 | 任一匹配 +0.15 |
| 弱项标签 | 0.15 | 每个匹配标签 +0.05，上限 0.15 |

### 弱项标签映射

Phase 4 发现的弱项指标会被映射为策略卡片的问题标签：

| 弱项 | 映射标签 |
|------|----------|
| 完播率低 | 完播率低、平均观看时长短 |
| 互动不足/互动率低 | 互动不足、评论率低、分享率低 |
| 点击率低 | 点击率低、曝光高点击低 |
| 转化率低 | 转化率低、点击率高但转化低 |
| 曝光低 | 曝光低 |

### 阈值与截断

- 最低分数阈值：0.15（低于此分数的卡片不返回）
- 最多返回：3 条
- 无匹配时：返回空数组 + 说明消息

## 检索输出

```typescript
interface RetrievalOutput {
  results: RetrievalResult[];   // Top 3（最多）
  noMatchMessage?: string;      // 无匹配时的说明
  input: RetrievalInput;        // 检索输入（用于调试）
}

interface RetrievalResult {
  card: StrategyCard;           // 策略卡片
  relevance_score: number;      // 相关性分数 0-1
  matched_fields: string[];     // 匹配的字段
  why_retrieved: string;        // 中文匹配原因
}
```

## 匹配原因示例

```
品类匹配（小家电/便携榨汁杯）；价格带匹配（50-99元）；
目标人群匹配（上班族）；问题标签匹配（完播率低）
```

## 设计原则

1. **可解释**：每个匹配都有明确的字段和原因说明
2. **确定性**：相同输入始终产生相同输出
3. **同步执行**：纯内存检索，无 I/O 依赖
4. **轻量**：无向量嵌入、无 TF-IDF、无余弦相似度

## 局限与未来改进

- 当前不支持语义相似度搜索
- 关键词匹配对同义词和表述差异不敏感
- 未来可引入轻量嵌入模型提升语义匹配精度
