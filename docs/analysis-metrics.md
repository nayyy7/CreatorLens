# CreatorLens 分析指标口径

> 基于 PRD V1.0 §8.3 和字段字典（Day 1 数据包），当前阶段仅使用确定性统计计算。

## 数据范围

- 仅使用 `record_status === "可分析"` 的记录参与统计
- 警告记录（`record_status === "警告"`）仍参与计算，但在报告中有对应提示
- 不可用记录完全排除

## 核心指标

### 整体指标（加权口径）

| 指标 | 公式 | 说明 |
|------|------|------|
| 整体互动率 | Σ(点赞+评论+收藏+分享) ÷ Σ(播放量) | 加权口径；分子为各项互动之和 |
| 整体商品点击率 | Σ(商品点击) ÷ Σ(播放量) | 仅在 product_clicks 字段存在时计算 |
| 整体转化率 | Σ(成交数) ÷ Σ(商品点击) | 仅在 orders 和 product_clicks 都存在时计算 |

### 单条指标（算术平均）

| 指标 | 公式 | 说明 |
|------|------|------|
| 平均完播率 | Σ(各条完播率) ÷ 有效记录数 | 仅计算有完播率字段的视频 |
| 平均 5 秒留存率 | Σ(各条 5 秒留存率) ÷ 有效记录数 | 仅计算有该字段的视频 |

### 分布指标

| 指标 | 公式 |
|------|------|
| 播放量中位数 | 排序后取中位 |
| 平均播放量 | Σ(播放量) ÷ 有效记录数 |

## 维度分组

### 分组依据

使用数据中实际存在的离散字段：
- `duration_band`（时长区间）
- `category`（品类，如有多于一种）
- `price_band`（价格带）
- `publish_month`（发布月份，由 publish_date 派生）
- `target_audience`（目标人群）

### 组内指标

| 指标 | 公式 |
|------|------|
| 样本量 | 组内记录数 |
| 平均播放量 | 组内播放量算术平均 |
| 中位数播放量 | 组内播放量中位数 |
| 整体互动率 | Σ(组内互动) ÷ Σ(组内播放) |
| 相对表现 | 组内平均播放量 ÷ 整体平均播放量 − 1 |

### 置信度

| 样本量 | 置信度 |
|--------|--------|
| 1 条 | 仅展示，不形成趋势结论 |
| 2 条 | 低 |
| 3-4 条 | 中 |
| ≥5 条 | 较高 |

## 洞察生成规则

| 规则 | 触发条件 | 方向 |
|------|----------|------|
| 最佳时长区间 | 不同时长区间 ≥2 组 | 推荐播放中位数最高的区间 |
| 互动率-播放关联 | 整体互动率存在 + Top 3 视频平均互动率 > 整体平均 | 正向关联 |
| 价格带差异 | 多个价格带 | 描述性呈现 |
| 完播率-播放关联 | 完播率数据 ≥3 条 + 高完播率组平均播放更高 | 正向关联 |

最多输出 3 条，按置信度和样本量排序；样本不足 3 条时不生成洞察。

## 边界处理

- 分母为 0：返回 null / "暂无数据"
- 空值字段：跳过该字段的计算
- NaN/Infinity：不产生，所有计算前检查分母
- 不可用记录：完全排除
